# 样式检查与证据

## 文本逐层检查

对页面总标题、章节标题、正文、列表、表单标签/值/占位符、按钮、提示类别/说明、文件名及辅助操作分别取样。长正文检查首、中、尾段，不能只检查总标题就断言正文正确。

记录 font-family、font-size、font-weight、line-height、color；对照 Figma family、style/weight、字号与行高。明确 400/500 的分层，确认实际字体是否加载；不同平台渲染造成的观感差异不直接当作字重错误。行高的百分比换算为 px 后比较，同时保留原始单位。

## 间距、尺寸与对齐

逐对检查总标题到首节、章节标题到正文、正文段落之间、区块到分隔线、标签到输入框、卡片到下一表单、侧栏标题到列表、文件标题到标签、操作区到内容区。

读取 flex/grid gap、margin、padding 与元素边界，说明测量起止元素；注意 margin 与 padding 叠加、首个元素特殊样式。文字内容不同导致的高度和换行差异不作为间距问题。记录实际值、设计值、差值和建议调整的容器/属性，不能只说“感觉紧”。

核对容器宽高、控件尺寸、左右栏比例、居中/边界对齐，排除缩放与设备像素比因素。截图记录内容视口宽高、缩放、DPR 和滚动区域。

## 颜色、线条、圆角

- 颜色：文本、背景、选中、禁用、提示及主要操作，区分 opacity、渐变和半透明叠色。
- 线条：每条边的宽度、颜色和样式，区分结构线、内容分隔、表格、输入框；不要将所有 0.5px 与 1px 全局替换。
- 圆角：按钮、输入框、提示条、选中菜单、标签、卡片、图片、弹窗和面板；记录四角 computed 值及设计值，检查同类组件 token 一致性。胶囊圆角数值差异若最终轮廓相同，应说明视觉影响，不能只凭大数值判断严重度。

## 判定与优先级

P0：视觉问题导致关键内容/操作不可使用；P1：明显影响阅读或主要层级；P2：局部偏差。只记录范围内可复现差异，不凑数量。

每条问题保存实际截图、坐标或矩形、Figma 节点（有稿时）、实际/期望参数、差异说明和可执行修改建议。无稿的响应式问题用视口边界等客观基准，明确标注“无设计稿，仅响应式”，不推测设计字号、字重或圆角。

历史问题若当前无法复现，记录当前证据和状态分支；保留原始问题，不擦除原描述，也不把“未能复现”直接等同修复通过。只有验证目标状态且参数匹配才标记已修复。

## 复核与收敛

1. 结构：页面/Frame/端别/状态映射，确认可访问性和范围。
2. 细查：逐层读取参数、放大截图、比较相邻元素与同类组件。
3. 复核：回看所有新增和本次修复项，并完整复查本次范围。

发现新问题后继续复查；最后一轮无新增才标记收敛。每轮保存真实范围、结论、剩余待复核项及新增数。页面打不开、Figma 没权限或测量不完整时保留部分结果，不能编造零问题结论或凑足轮次；不完整结果作为草稿保留，不发布成完整批次。
