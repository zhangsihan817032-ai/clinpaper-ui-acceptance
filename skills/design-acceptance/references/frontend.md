# 前端源码解析参考

适用 PC、移动网页及 App 内 H5。共用判定、状态及证据规则见 [主流程](../SKILL.md)，环境入口见 [projects.md](projects.md)。

## 页面与生效样式

- 从路由、模板追到实际组件、子组件和状态分支；先确认框架、样式方案和构建入口，不按文件后缀猜测线上使用情况。
- 追踪 CSS 选择器优先级、加载顺序、继承、变量、主题、行内样式、媒体查询和 important。默认值或 fallback 只有在对应条件成立时才是生效值。
- 字体核验加载成功与否、回退字体、字重、行高、字距、文本省略及伪元素。声明某字体不代表目标设备实际使用该字体。
- 布局核验 box-sizing、flex/grid、gap、padding、margin、约束、最小尺寸、overflow、定位及 transform。区分父容器间距和元素自身高度，不把分页器本身高度算成上下间距。
- 检查 button、input 等控件的浏览器默认 appearance、padding、border、基线及状态样式；Safari/WebView 与桌面浏览器分开确认。

## 图片与合成图

先辨明灰块、留白、遮罩位于图片内部还是展示容器：追踪接口数据、图片原始像素、背景与占位状态，再看 width/height、aspect-ratio、object-fit、object-position、裁切及错误兜底。

合成图要查画布尺寸、初始化填色、绘制坐标、文本测量、图片缩放、导出和后处理。某段源码未画灰块只说明该路径未显式绘制，不能排除其他生成路径、旧部署或展示占位层。

## 单位与运行验证

CSS px、截图物理像素、DPR、浏览器缩放、rem/vw 和 transform 分别记录；先匹配设计稿内容区域和视口，再比较。移动端无指定尺寸时可从 390 × 844 CSS px 起查，断点相关问题补查 375/430 等宽度；PC 优先匹配目标 frame 宽度。

二次源码验收按主流程核对选择器、资源、组件和覆盖后的生效参数。需要运行验证时使用目标提交原页面或原组件，保留原主题、字体、图标与布局依赖；演示数据、隔离范围和外部依赖缺失均注明。用 computedStyle 与 boundingClientRect 验证推导，交互状态按当前任务实际触发。

source-render 只证明该提交组件在所述环境的效果，不代表线上完整 App。手工重画的 HTML 或源码文字图不能作为目标组件的渲染证据；不能补画原生导航后冒充 App 截图。

## Hybrid 边界

分别记录 App 构建、原生容器、实际加载的 H5 包/地址、bridge 参数、容器尺寸、安全区和滚动区域。App 版本号不自动等于 H5 版本。

定位偏差时拆分原生导航/容器与 H5 内容区域。已确认由 H5 实现引起的新问题归前端，并在说明中记录发生的 iOS/Android/鸿蒙端；未知归属遵循主流程，保留待确认。

## 最少取证内容

组件调用链及完整提交号；相关状态与主题；关键声明与推导的生效值；设计参数及 node。实际取图或运行验收另记双图、视口、原图坐标及部署映射。详细依据折叠，写入格式见 [report.md](report.md)。
